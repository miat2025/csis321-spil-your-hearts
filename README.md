# csis321-spil-your-hearts
A project that helps students be more involved with weekday chapel services at George Fox University in hopes of creating more interest. 

### What are we building?
We are building a website for diversity, communication, and connection to the George Fox community. The website is aimed to provide students a view of chapel services and  what will be covered for each day it is offered.

### Why are we building it? 
The problem is that those who attend chapel don’t always connect with the service, and our goal is to better tailor chapel to those attending. This is so the students can feel seen, have less fines, and give input on what they want to do and see.

### How is the repository organized? 
The repository features different folders for the source code, testers, and documentation of decisions made, website planning, etc.
